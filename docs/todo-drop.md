# TODO 浮層（⌘⇧L）

在 agent 工作時先記下「之後想請 agent 做的事」，不影響目前 agent 的作業。浮層置中顯示；agent 做完後叫出來，勾選項目，合併貼進目前終端機（**只貼上，不按 Enter**）。

## 範圍與資料

- 全域一份清單，項目可分類（自由字串，空字串＝未分類）。
- `data_dir/todos.json`：`{ revision, items: [{ id, text, category, createdAt }] }`。
- `src-tauri/src/todos.rs`：原子寫入、`revision` 樂觀鎖（多視窗），寫入後 emit `todos-changed`。內容不可空白、不可含 NUL、最長 20000 字；分類最長 40 字、不可含換行。
- 勾選狀態只存在記憶體，每次開啟都會清空。

## 送出格式

- 純邏輯在 `src/todo.ts` 的 `formatSend`：
  - 勾選一項：原文。
  - 勾選多項：每項前加 `- `，項目之間空一行，多行項目的續行縮排兩格。
- 送出走 `insert-text`（bracketed paste，多行不會被當成 Enter），之後 `focus` 回終端機；**不送 `key enter`**。
- 送出成功後，已送出的項目從清單移除。貼上失敗時不移除。

## 疊在終端機之上

與待處理浮層相同（見 `docs/attention.md`、`docs/snippet-palette.md`）：

- 面板置中（`top:50%; translate(-50%, -50%)`），靠 `overlay-cutout` 挖洞顯示，關閉時送全零。
- 面板大小或工作區大小改變時會重送矩形（監看面板與父層的 `ResizeObserver`）；置中後位置會跟著變，不能只監看面板本身。
- 與 ⌘⇧P 片段面板、待處理、用量浮層共用 `default` 遮罩，互斥：開任一個前先關其他。

## 鍵盤

⌘⇧L 在原生 local monitor 攔截（`bridge.m`，與 ⌘⇧P 同處），因為終端機聚焦時按鍵不會到 WebView。

| 按鍵 | 動作 |
|---|---|
| ↵（輸入框、分類欄） | 新增項目 |
| ⇧↵（輸入框、編輯區） | 換行 |
| ↵（編輯區） | 儲存編輯 |
| Esc | 關閉並把焦點還給終端機（編輯中則先取消編輯） |

輸入法選字中（`isComposing`）不處理 Enter／Esc。

## 關閉後的焦點

所有關閉路徑（Esc、再按 ⌘⇧L、點面板外、送出）都要把焦點還給終端機；點到輸入元素或視窗失焦（blur）除外。`open()` 的 `focus-web` 是非同步，期間若已被關閉要改回終端機。

## 維護

- 面板高度固定（最高 560px、不超過工作區），項目多時在清單區捲動，輸入區與底部按鈕位置不變。
- 項目可新增、勾選、編輯（行內）、刪除；分類 chips 過濾。
- 開啟時預設篩選與新增的分類都是當前頁籤名稱（沒有頁籤時是「全部」）。目前的篩選即使沒有項目也會保留 chip，可按「全部」清除。
- 「刪除已勾選」一次刪掉所有勾選項目（不受目前過濾影響），沒有二次確認，與列上的「刪除」相同。
- 分類輸入框的建議來自既有分類（`datalist`）。
- 文字都經 `t()` 或 `data-i18n*`，見 `src/locales/*/todo.json`。

## 驗收清單（`npm test` 不涵蓋，需實機；debug 與 release 各做一次）

1. 終端機聚焦時 ⌘⇧L 開啟；再按一次或 Esc 關閉，焦點回終端機，`stty size` 前後不變。
2. WebView 聚焦（例如剛點了標題列）時 ⌘⇧L 也能開啟。
3. 面板置中，蓋在終端機上方；洞內可點擊，洞外仍可點終端機。
4. 按 ↵ 直接新增；⇧↵ 換行後再按 ↵ 新增多行項目；貼上多行文字；中文輸入法選字中按 ↵ 不會誤新增。
5. 勾選 2 項送出：終端機收到合併文字（`- ` 清單），游標停在最後，**沒有執行**；已送出項目從清單消失。
6. 無頁籤時送出按鈕停用。
7. 分類 chips 過濾正確；編輯、刪除、取消編輯（Esc 只取消編輯，不關面板）。
8. 與 ⌘⇧P 面板、待處理、用量浮層互斥；與檔案面板可共存。
9. 視窗縮放、切換分割、開關側欄（工作區大小改變）時，遮罩位置正確、關閉後無殘影。
10. 重啟 App 後清單仍在；兩個視窗之間一邊新增，另一邊自動更新；同時編輯出現衝突時顯示重新載入後的版本。
11. 照 `docs/keyboard-input.md` 確認 ⌘⇧L 的 local monitor 沒有影響一般輸入。
