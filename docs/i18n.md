# 多國語系（i18n）

設定頁「語言」可指定介面語系；預設「跟隨系統」，沒有對應語系檔時用英文。內建 `en`（完整基準、fallback）與 `zh-Hant`；語系檔可匯入，也可在 App 內用簡易編輯器修改。

## 範圍
- 翻譯：前端所有 UI、原生右鍵選單／NSAlert／NSOpenPanel 的提示文字（`bridge.m`）。
- **不翻**：Rust 錯誤訊息、`highostty ctl` 回覆（`src/control.ts`，給 agent 看）、`files.m` 錯誤字串、`warning` 事件內容。

## 檔案與格式
- 內建：`src/locales/<code>/*.json`，每個檔案是一個區域（`files`、`snippets`、`app`、`settings`…）的扁平 dotted key，載入時合併（`src/locales/index.ts`，Vite glob）。新增區域檔不需登記。
- 使用者：資料目錄的 `locales/<code>.json`（`HIGHOSTTY_DATA_DIR` 可隔離）；設定在 `settings.json` 的 `language`（`"system"` 或語系代碼）。
```json
{ "_meta": { "locale": "ja", "name": "日本語" },
  "messages": { "settings.title": "設定", "files.itemCount.other": "{n} 件" } }
```
- 代碼規則 `^[a-z]{2,3}(-[A-Za-z0-9]{2,8})*$`（會成為檔名；前端 `validLocaleCode` 與 Rust `valid_code` 同一條）。
- 參數 `{name}`；複數用 `key.one`／`key.other`…（依 `Intl.PluralRules`），呼叫 `t(key, { n })`。缺翻譯退回英文時用英文的複數規則。
- 使用者檔逐 key 覆蓋同代碼內建語系（內建檔唯讀）；缺的 key 依序退回 en、再退回 key 本身。

## 程式分工
- `src/i18n.ts`：純邏輯（解析驗證、`resolveLocale`、`createTranslator`、合併／差異）與目前的 `t()`。**必須 DOM-free**，才能被 `files.ts`、`snippets.ts`、`model.ts` 這類純邏輯模組與 node 測試 import；這些模組要寫 `from "./i18n.ts"`（含副檔名，node strip-types 需要）。
- `src/i18n-runtime.ts`：載入設定與使用者語系、`applyI18n`、`onLocaleChange`；監聽 `language-changed`／`locales-changed`（Rust 寫入後廣播，所有視窗同步）。
- `src/language-settings.ts`：設定頁「語言」區塊（選擇、匯入、匯出、新增）與 drawer 詳細頁 `edit-locale` 編輯器。
- `src-tauri/src/locales.rs`：設定、語系檔的讀寫（原子寫入）、檔名驗證。檔案選擇走原生 `pick-file`／`save-file` op（不用 dialog plugin）。
- `bridge.m`：`set-strings` 接收 `native.*` 字串（`L(key, fallback)` 取用，fallback 為英文）；`preferred-languages` 回 `NSLocale.preferredLanguages`。

## 寫程式時
- 靜態 HTML：英文預設文字＋`data-i18n`／`data-i18n-title`／`data-i18n-aria-label`／`data-i18n-placeholder`。
- 動態字串：呼叫時才 `t("key")`，不要在模組載入時快取。
- 新增字串一律同步補 `src/locales/en/*.json` 與 `zh-Hant/*.json`（key 集合與 `{參數}` 必須一致，`tests/i18n.test.mjs` 會檢查，也會檢查程式碼用到的 key 都存在於 en）。
- 會跟著語系變動的畫面要在 `onLocaleChange` 重畫；編輯器（表單）不要重建，會丟掉輸入。
- 系統語言取自原生（WKWebView 的 `navigator.languages` 不一定等於系統偏好）；沒有原生引擎的視窗（預覽窗）退回 `navigator.languages`。
- 驗證規則（`prompt-rules.ts`）等純邏輯回傳結構化錯誤（key＋參數），顯示時才翻譯。

## 編輯器
設定頁「語言」→「編輯」／「新增語系…」開啟 drawer 詳細頁：以英文 key 為基準列出所有字串，可搜尋、只看未翻譯，`{參數}` 與英文不一致會警告。只存與內建不同的 key；內建語系可「還原為內建」，自訂語系可刪除。

## 驗收清單（實機，debug 與 release 各做一次）
1. 系統語言為繁中 → 預設繁中；改成日文（無日文語系檔）→ 英文。
2. 設定切換 en ⇄ zh-Hant：側欄、設定頁、檔案面板與右鍵選單、終端機右鍵選單、剪貼簿權限 NSAlert、匯出失敗提示、目錄選擇器按鈕、預覽窗、所有開著的視窗即時切換；終端機不中斷、編輯器內輸入不丟。
3. 匯入合法 `ja.json` → 出現在選單並可切換；匯入損壞檔（壞 JSON、`_meta.locale` 不合法、值非字串）→ 顯示原因、目前語言不變。
4. 編輯器：搜尋、只看未翻譯、修改後存檔即時生效、還原為內建、匯出後再匯入結果一致。
5. 手動把壞掉的檔案放進 `locales/` → 設定頁顯示「已忽略」，其餘語系正常。
